## 專案簡介

以《天堂》為主題的瀏覽器放置遊戲，使用原生 HTML／CSS／JavaScript 製作，
存檔保存在瀏覽器 localStorage。內容包含職業、裝備、掉落、任務、寵物、
召喚、潘朵拉黑市、遺物、攻城等系統。

## 與 shines871 版本的差異

本專案基於 [shines871/idle-lineage-class](https://github.com/shines871/idle-lineage-class)，
目前版本約 **v3.8.37**，主要差異如下：

| 項目 | shines871 版 | 本版 |
|---|---|---|
| 快速回收 | 僅快速強化／快速廢品 | 新增批次快速回收（武器／防具／道具），可選金幣、龍鑽、卷軸；回收價為售價 50%~150%；+N 裝備可換 N 張對應施法卷軸；1 龍鑽 = 100 萬金幣 |
| 潘朵拉黑市 | 被動刷新 | 新增「全部刷新」「輪換 1 件」手動刷新（免費）；購買可設定數量；商品卡顯示數量 |
| 遺物布告欄 | 搜尋 100 龍鑽；完成／取消後 24 小時冷卻 | 搜尋 1 龍鑽；移除 24 小時冷卻 |
| 席琳結晶 | 僅能兌換席琳遺骸 | 伊奧新增「受祝福的武器／盔甲施法卷軸」（1 結晶／張），可批次兌換；原遺骸兌換保留 |
| 傲慢之塔 | 傳送符＋100 移動卷軸 → 支配符 | 新增「500 移動卷軸 → 傳送符」；原支配符配方保留 |
| 召喚系統 | 安全區不能召喚；重新施放固定召喚物 | 移除安全區限制；戴召喚控制戒指可按「重新施放」重選；選完立即施放 |
| 怪物血條 | 預設關閉 | 預設開啟（仍可關閉） |
| 其他 | — | 世界頻道提示、UI／CSS、版本號更新至 v3.8.37 |

## 執行方式

1. 安裝 Python 3。
2. 雙擊 `start.bat`，瀏覽器會開啟 `http://127.0.0.1:8011/`。
3. 關閉伺服器可執行 `stop.bat`，或在原視窗按 `Ctrl+C`。

也可以使用任何靜態檔案伺服器指向專案根目錄。
